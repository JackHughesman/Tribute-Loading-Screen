## 🛠 Installation Instructions

⚠️ This resource is designed to be easy to install.



### Step 1  Install the Script

1️⃣ Download the resource  
2️⃣ Extract the folder  
3️⃣ Place the folder into your server resources directory

Example location

```
resources/mystic-chat/
```



### Step 2  Add to Server Config

Open your server.cfg file and add the following line

```
start mystic-chat
```

Make sure the folder name matches exactly.



### Step 3  Restart the Server

🔁 Fully restart your FiveM server

The custom chat will automatically load when the server starts.



## 🧩 Troubleshooting

• Ensure the folder name matches the entry in server.cfg  
• Restart the server after making changes  
• Make sure no other chat resources conflict with this script
